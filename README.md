<p align="center">A Flutter-based mobile application that allows users to explore a variety of categorized meals and filter them based on dietary preferences. Developed with Flutter and the riverpod package, this app provides a seamless user experience for meal selection and personalization.</p>


## Features  
- **Meal Display:** Browse through a wide selection of meals with detailed information, including ingredients, preparation steps, and nutritional facts.
- **Categorization:** Meals are organized into categories, making it easier for users to find what they are looking for, whether it's breakfast, lunch, dinner, or a specific cuisine.
- **Favorites:** Users can mark meals as favorites for quick access later on.
- **Filters:** Users can apply filters such as gluten-free, lactose-free, vegetarian, and vegan to tailor meal suggestions according to their dietary needs.
- **State Management:** The app uses the riverpod package to efficiently manage state across the application, ensuring smooth and responsive navigation.

## Dependencies

This app relies on several key dependencies to provide its functionality:
-  [**flutter_riverpod**](https://pub.dev/packages/flutter_riverpod) A modern state management solution for Flutter that provides a robust, scalable, and testable architecture for managing app state.
-  [**transparent_image**](https://pub.dev/packages/transparent_image) A Flutter package that allows the use of transparent placeholder images while the actual image is loading, improving user experience in image-heavy apps.
 
## Installation
To get started with this project , follow these steps:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/nadahossamismail/Meal-App.git
    cd meal_app
    ```
    
2. **Install dependencies:**
    ```bash
    flutter pub get
    ```

3. **Run the app:**
    ```bash
    flutter run
    ```
